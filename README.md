# MyWebPage – Full Stack Web Application

A full-stack web application built with a **React.js frontend**, **Django (Python) backend**, and **PostgreSQL** database. The application demonstrates end-to-end web development, including RESTful APIs, database modeling, and dynamic user interfaces.

---

## 🔧 Tech Stack

**Frontend**
- React.js
- JavaScript (ES6+)
- HTML5 / CSS3

**Backend**
- Django (Python)
- Django REST Framework
- Node.js (supporting services / tooling)

**Database**
- PostgreSQL

**Tools & Workflow**
- Git & GitHub
- RESTful API architecture
- Environment-based configuration

---

## ✨ Features

- Full CRUD functionality for application data
- RESTful API built with Django and consumed by the React frontend
- PostgreSQL database with structured relational models
- Dynamic, component-based UI using React
- Backend validation and data persistence
- Modular project structure separating frontend and backend concerns
